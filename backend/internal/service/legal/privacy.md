AiFerry（以下简称"本平台"）重视用户的个人信息与数据安全，仅收集、存储提供服务所必需的数据。本政策说明本平台收集和存储的数据范围、用途及用户享有的权利。

## 一、本平台收集和存储的数据

1. **账户信息**：包括邮箱、登录方式、充值及订阅记录，用于账户登录与费用结算。
2. **调用记录**：包括每次请求的时间、所调用的模型、所用 API 密钥、Token 用量、响应耗时、费用，以及发起请求的 IP 地址和客户端标识（User-Agent），用于计费、对账及防范滥用。用户可在用量页查阅本人的调用记录。

## 二、本平台不存储的数据

1. **请求成功时，本平台不存储用户发送的请求内容，亦不存储模型返回的内容。**
2. 请求失败时，为排查故障，本平台将保存该次请求的内容及错误信息，其中的密钥等凭据信息会被移除；**上述数据自保存之日起 30 天后自动删除**。
3. 如本平台为防范滥用启用内容安全审计，被审计的请求内容将予以留存用于审查，且仅限必要人员访问。

## 三、本平台的承诺

1. **本平台不出售、不出租用户的任何数据。**
2. **本平台不使用用户的数据训练模型。**
3. 除法律法规另有规定或有权机关依法要求外，本平台不向任何第三方提供用户的数据。

## 四、上游模型提供方对数据的处理

为完成用户的请求，请求内容须发送至相应模型的上游提供方进行处理。上游提供方将依据其自身的隐私政策处理相关内容，部分上游提供方可能出于防范滥用的目的对请求进行短期留存。

## 五、用户的权利

1. 用户可随时在控制台删除 API 密钥、查阅本人的全部调用记录；
2. 用户可联系本平台申请注销账户。账户注销后，本平台将依照法律法规的规定处理相关数据。
