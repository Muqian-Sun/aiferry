AiFerry（以下简称"本平台"）重视用户的个人信息与数据安全，仅收集、存储提供服务所必需的数据。本政策说明本平台收集和存储的数据范围、用途及用户享有的权利。

## 一、本平台收集和存储的数据

1. **账户信息**：包括邮箱、登录方式、充值及订阅记录，用于账户登录与费用结算。
2. **调用记录**：包括每次请求的时间、所调用的模型、所用 API 密钥、Token 用量、响应耗时、费用，以及发起请求的 IP 地址和客户端标识（User-Agent），用于计费、对账及防范滥用。调用记录保留 90 天，用户可在用量页查阅本人的调用记录。

## 二、请求内容的处理

1. **本平台不存储用户发送的请求内容，亦不存储模型返回的内容。**请求成功或失败均是如此，仅有以下例外。
2. **请求失败时**，为排查故障，本平台保存错误信息，包括返回给用户的错误内容和上游返回的错误信息（上游的错误信息可能引用请求中的片段）；无法解析的请求，服务日志会记录其开头和结尾各 256 字节。密钥等凭据信息会被移除。**上述数据自保存之日起 30 天后自动删除。**
3. **协议转换时**，如请求需在不同协议之间转换（例如以 Responses 协议调用仅支持 Chat Completions 协议的上游），为在后续对话中回传模型的推理过程，本平台会缓存模型输出的推理摘要，**7 天后自动删除**。
4. **内容安全审计**默认不开启。如本平台为防范滥用而开启，被审计的请求内容会发送至所配置的审核服务；被判定为违规的请求内容将予以留存，仅限必要人员访问，其中审核摘录保留 180 天，完整内容由人员审查后删除。审计设置也可选择留存未违规的请求，其审核摘录保留不超过 3 天，完整内容同样由人员审查后删除。

## 三、本平台的承诺

1. **本平台不出售、不出租用户的任何数据。**
2. **本平台不使用用户的数据训练模型。**
3. 除完成请求所必需（见第二、四条）及法律法规另有规定或有权机关依法要求外，本平台不向任何第三方提供用户的数据。

## 四、上游模型提供方对数据的处理

为完成用户的请求，请求内容须发送至相应模型的上游提供方进行处理。上游提供方将依据其自身的隐私政策处理相关内容，部分上游提供方可能出于防范滥用的目的对请求进行短期留存。

## 五、用户的权利

1. 用户可随时在控制台删除 API 密钥、查阅本人近 90 天的调用记录；
2. 用户可联系本平台申请注销账户。账户注销后，本平台将依照法律法规的规定处理相关数据。
