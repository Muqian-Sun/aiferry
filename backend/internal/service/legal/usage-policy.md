## 一、禁止生成、传播的内容

用户不得利用本平台生成、复制、发布或传播下列内容：

1. 违反法律、行政法规的内容，以及涉及未成年人的色情或其他侵害未成年人权益的内容；
2. 煽动暴力、宣扬恐怖主义或极端主义，或对他人、特定群体进行歧视、仇恨、骚扰的内容；
3. 制造武器、实施严重人身伤害的具体方法；
4. 恶意软件，以及用于未经授权侵入、破坏计算机信息系统的程序或代码；
5. 用于诈骗、网络钓鱼、洗钱、赌博等违法犯罪活动的材料；
6. 侵犯他人著作权、隐私权、名誉权等合法权益的内容，冒用他人身份或足以误导公众的虚假内容。

## 二、禁止的使用行为

用户不得从事下列行为：

1. 未经授权收集、处理或分析他人的个人信息；
2. 以伪造请求或其他任何方式规避本平台或上游模型的安全审核、计费及限速机制；
3. 对本平台实施网络攻击、压力测试或漏洞扫描；
4. 将 API 密钥转售、出租、出借给他人，或将本平台接口包装为独立服务对外提供；
5. 批量注册账户，或以不正当手段获取活动权益、邀请奖励。

## 三、上游服务的使用规范

本平台所接入的模型均由相应的上游提供方运营。用户在调用各模型时，除遵守本政策外，还应当遵守该模型上游提供方发布的使用政策。

对于违反本政策的行为，本平台有权视情节轻重采取限制调用频率、停用 API 密钥、冻结或注销账户等措施；涉嫌违法犯罪的，本平台将依法向有关主管部门报告。
